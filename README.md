# IRO – Issues Reporting Outlet

## Project Description

IRO (Issues Reporting Outlet) is a proposed web-based platform
designed to provide an organized channel for reporting issues
affecting AAUA students and surrounding indigenous communities.

## Target Users

- AAUA Students
- Akungba-Akoko Indigenes
- Iwaro Indigenes
- Etioro Indigenes
- Ayegunle Indigenes
- Other surrounding communities

## Objectives

1. Provide an accessible platform for reporting issues.
2. Improve communication between students and indigenous communities.
3. Provide a means of tracking submitted reports.
4. Support anonymous reporting for sensitive issues.
5. Improve documentation and management of reported issues.

## Main Features

- Issue reporting
- Student/Indigene identification
- Community/location selection
- Issue categorization
- Urgency classification
- Anonymous reporting
- Report ID generation
- Report tracking

## Technologies

- HTML
- CSS
- JavaScript
- Browser Local Storage
